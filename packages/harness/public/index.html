BRING YOUR OWN AGENT
Một harness, nhiều lối vào.
Chạy local từ trình duyệt, gọi qua MCP trong Codex, hoặc đưa plan từ ChatGPT vào đây.
01
Ghép nối trình duyệt
Nhập pairing token được in trong terminal khi khởi động server. Token chỉ giữ trong bộ nhớ của tab này.
Đóng hoặc tải lại tab sẽ cần ghép nối lại.
02
Codex qua MCP
Chạy MCP stdio từ checkout OhMyWork. Thay đường dẫn bằng vị trí repo trên máy của bạn.
codex mcp add ohmywork_harness -- node /absolute/path/ohmywork/packages/harness/cli.mjs mcp --workspace /absolute/path/your-project
Muốn cho phép sửa code, thêm --allow-execution khi chạy MCP server.
03
ChatGPT → local harness
Nhờ ChatGPT tạo plan JSON, rồi import ở màn hình Tổng quan. Đây là cách chuyển plan thủ công, không cần cấp quyền truy cập máy.
{"goal":"Mục tiêu của bạn","tasks":["Task 1","Task 2"]}
04
ChatGPT qua MCP tunnel
Để ChatGPT gọi trực tiếp, cần cấu hình một MCP tunnel hoặc endpoint phù hợp cho server stdio này, rồi thêm vào ChatGPT.
ChatGPT trên cloud không tự truy cập localhost. Chưa có tunnel nào được thiết lập bởi ứng dụng.
