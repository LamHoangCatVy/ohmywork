# Local harness run report

| Field | Evidence |
| --- | --- |
| Run ID | Returned by runtime |
| Workspace | Approved absolute path |
| Goal and authorized scope | Agreed change boundary |
| Mode and observed status | Plan or execute; actual terminal status |
| Limits | Maximum iterations and timeout |
| Changed files | Inspected diff or none |
| Review | Findings, severity, and disposition |
| Token usage | Counts emitted by Codex, or unavailable; never remaining quota |

## Independent validation

| Check | Evidence source | Result |
| --- | --- | --- |
| Project check | Command/output or inspected CI evidence | Passed, failed, skipped, or pending |

## Unresolved work

Record blocked tasks, skipped checks, partial edits, and decisions requiring a human or environment.

## Next action

State the next concrete step and whether it is already within the authorized scope.
