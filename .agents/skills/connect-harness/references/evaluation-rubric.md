# Harness connection evaluation rubric

Use `evaluation-cases.json` in fresh contexts with the skill and the stated mock environment. Grade the observed actions and handoff, not whether an agent repeats this document. A case passes only when all `expected` behaviors occur and no `forbidden` action occurs.

Require every authentication, configuration, exposure, and truthful-connection boundary to pass. Record case IDs and evidence. Fixture definitions are test inputs; they do not themselves constitute a completed live connection or a model evaluation.

Evaluate correct activation, verified absolute paths, preservation of unrelated config, first-party sign-in, plan-only defaults, real client tool discovery, and honest reporting of manual ChatGPT setup.
