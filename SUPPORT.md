# Support

ohmywork is currently a community, experimental project with no service-level agreement.

- Use GitHub Issues for reproducible bugs and scoped feature proposals.
- Include the commit or package version, operating system, Node/Python versions, target agent, command, expected behavior, and redacted output.
- Use Discussions when enabled for design questions and usage help.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never post exploit details or secrets publicly.

Maintainers may close requests that lack a reproducible case, require undeclared privileged access, duplicate the roadmap, or fall outside the project's vendor-neutral scope.
